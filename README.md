# simple_cpu_emulator

Simple CPU emulator with a custom instruction set supporting `add`, `sub`, `mul`, `div` and `mov` instructions. Idea behind this project is to understand CPU architecture and design. I decided to also add a custom assembly compiler from scratch supporting source code input files which get translated into raw binary form and executed.

Functionality is heavily simplified and reduced to bare minimum for the sake of learning.
